# FoodInsightAI

A multi-agent, retrieval-grounded food assistant for nutrition, allergen
screening, recipes, and ingredient substitution.

> Status: in development (20-day build). See `docs/progress.md`.

## What it will do
- Answer food questions with cited sources (RAG)
- Compute nutrient totals in code, not by LLM guesswork
- Screen ingredients for allergens with deterministic rules
- Generate recipes and suggest substitutions
- Personalize suggestions by diet, allergies, and goals
